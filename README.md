
# credit-risk-scorecard
信贷风控评分卡建模项目，金融科技方向，实现完整信贷违约预测流程。

## 项目简介
本项目基于公开贷款数据集，构建客户违约预测模型，模拟银行信贷风控业务。
完整流程：数据探索EDA → 数据清洗（缺失值、异常值IQR处理）→ 特征工程（分箱、WOE、IV筛选）→ 模型训练 → 模型评估。
对比传统逻辑回归评分卡与XGBoost、LightGBM集成模型，使用AUC、KS、ROC曲线评估模型效果。

## 数据集
采用LendingClub公开贷款数据集，任务为二分类：预测借款人是否发生贷款违约。
> 数据集不包含真实客户隐私，可在Kaggle下载。
